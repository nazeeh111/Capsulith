# Security reporting

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting when enabled. Do not include unpatched exploit details in a public issue. If private reporting is unavailable, open a public issue requesting a private contact without technical vulnerability details.

Capsulith parses supplied binaries as bytes. Native controls in examples rebuild and load only the known-source specimens. Guest instructions run inside the pinned Wasm emulator in a separate worker with logical memory bounds and execution budgets. These controls are not a guarantee against vulnerabilities in the emulator, Python, Capstone, Node or the browser. Use a separate disposable environment for untrusted artifacts.

The local Studio binds 127.0.0.1, checks Host/Origin, admits at most16 simultaneous connections and processes at most2 POST requests at once. Artifact/request/output ceilings and worker deadlines are explicit. No arbitrary path, native execution, shell, network or import callback is exposed by its API.
