What this preserves
Actual RGBA bytes and an owned native allocation. The checkpoint records region state and limits at a completed method boundary. It does not capture arbitrary CPU or stack frames.

      


    

    
Prepared code, explicit scope. This is a bounded ARM64 QOI component, with declared calling contracts and memory imports. It does not infer object fields or load arbitrary native applications. PNG pixels and PNG downloads use browser image APIs; QOI encode/decode and restored allocation free use original compiled instructions. Pixel equality compares RGBA bytes, not original PNG file bytes.
